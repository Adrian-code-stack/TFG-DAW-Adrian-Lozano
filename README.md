# GameVault 🎮

Portal web de videojuegos desarrollado como Proyecto Final del ciclo DAW.

🌐 **Demo en producción:** https://www.gamevault.es

## Stack
- **Frontend:** Astro 5 + Tailwind CSS (SSR)
- **Backend:** Node.js + Express + JWT
- **Base de datos:** MariaDB
- **API externa:** RAWG (rawg.io)
- **Despliegue:** Hetzner VPS + Nginx + PM2 + Let's Encrypt
